# Changelog

## 1.0.1

- Show your own picture inside the ring: save it as `%USERPROFILE%\.claude-usage-widget\center.png`.
- Smaller download: no longer bundles numpy, which the widget never used.
- The app now carries its name and version in its file details (Task Manager, file properties).
- Fuller README: download link, troubleshooting, FAQ. Added SECURITY.md and a bug report template.

## 1.0.0

- First release: floating button with the weekly usage ring and percentage, a panel with every limit
  and reset time, sign-in through Claude Code, follows account switches, backs off when rate limited,
  Windows installer with start at sign-in and uninstall.
